Fixed mobile bottom navigation for WordPress: ten UI styles, Font Awesome icons, colors, badges, RTL, and a full settings panel.

== Description ==

Mobile Menu Bar یک پلاگین حرفه‌ای وردپرس است که یک منوی موبایل زیبا و کاربردی برای سایت شما ایجاد می‌کند. این پلاگین کاملاً بر اساس استانداردهای مخزن وردپرس توسعه یافته و شامل 10 استایل مختلف UI/UX است.

= امکانات اصلی =

* **10 استایل مختلف UI/UX:**
  - Classic Bottom Bar - منوی کلاسیک با انیمیشن ساده
  - iOS Glassmorphism - شیشه‌ای شبیه iOS با blur
  - Floating Pill - شناور با فرم گرد
  - Material Design - متریال دیزاین با سایه
  - Gradient Wave - گرادیانت موجی
  - Neumorphism - نیومورفیسم با سایه نرم
  - Minimal Line - مینیمال با خط
  - Bubble Pop - حباب‌های شناور
  - Neon Glow - نئون با درخشش
  - Card Slide - کارتی با اسلاید

* **قابلیت تنظیم آیتم‌ها:**
  - حداقل 3 و حداکثر 5 آیتم قابل افزودن
  - انتخاب آیکون از کتابخانه Font Awesome
  - لینک سفارشی برای هر آیتم
  - نمایش Badge برای نوتیفیکیشن‌ها
  - فعال/غیرفعال کردن هر آیتم

* **سفارشی‌سازی رنگ:**
  - رنگ اصلی (Primary)
  - رنگ ثانویه (Secondary)
  - رنگ پس‌زمینه
  - رنگ آیکون
  - رنگ حالت فعال

* **ویژگی‌های پیشرفته:**
  - نمایش فقط در موبایل (زیر 768 پیکسل)
  - پنل مدیریت کامل و کاربرپسند
  - انیمیشن‌های روان و جذاب
  - پشتیبانی از RTL
  - سازگار با تم تاریک
  - بهینه‌سازی شده برای عملکرد
  - پشتیبانی از Accessibility
  - کاملاً ریسپانسیو

* **استاندارد وردپرس:**
  - کد نویسی بر اساس WordPress Coding Standards
  - استفاده از WordPress API
  - Sanitization و Validation کامل
  - امنیت بالا با استفاده از Nonce
  - بهینه‌سازی شده برای SEO

== Installation ==

= نصب خودکار =
1. به پیشخوان وردپرس خود بروید
2. به منوی 'افزونه‌ها > افزودن' بروید
3. عبارت 'Mobile Menu Bar' را جستجو کنید
4. روی دکمه 'نصب' کلیک کنید
5. پلاگین را فعال کنید

= نصب دستی =
1. فایل پلاگین را دانلود کنید
2. فایل zip را در مسیر `/wp-content/plugins/` استخراج کنید
3. به منوی 'افزونه‌ها' در وردپرس بروید
4. پلاگین 'Mobile Menu Bar' را فعال کنید
5. به منوی 'Mobile Menu' بروید و تنظیمات را انجام دهید

= پیکربندی =
1. بعد از فعال‌سازی، به منوی 'Mobile Menu' بروید
2. در تب 'آیتم‌های منو' آیتم‌های دلخواه خود را اضافه کنید
3. برای هر آیتم:
   - آیکون Font Awesome را وارد کنید (مثال: fas fa-home)
   - برچسب را وارد کنید
   - لینک را تنظیم کنید
   - در صورت نیاز Badge اضافه کنید
4. از تب 'استایل‌ها' یکی از 10 استایل را انتخاب کنید
5. در تب 'رنگ‌ها' رنگ‌های دلخواه را تنظیم کنید
6. روی 'ذخیره تنظیمات' کلیک کنید

== Frequently Asked Questions ==

= چگونه آیکون اضافه کنم؟ =

از کلاس‌های Font Awesome 6 استفاده کنید. مثال:
- fas fa-home (خانه)
- fas fa-search (جستجو)
- fas fa-user (کاربر)
- fas fa-bell (اعلان)
- fas fa-shopping-cart (سبد خرید)

لیست کامل آیکون‌ها را در https://fontawesome.com/icons مشاهده کنید.

= چند آیتم می‌توانم اضافه کنم؟ =

حداقل 3 و حداکثر 5 آیتم می‌توانید به منو اضافه کنید. این تعداد برای UX بهینه در موبایل انتخاب شده است.

= آیا در دسکتاپ نمایش داده می‌شود؟ =

خیر، این منو فقط در نمای موبایل (صفحه‌نمایش‌های زیر 768 پیکسل) نمایش داده می‌شود.

= چگونه Badge اضافه کنم؟ =

در قسمت تنظیمات هر آیتم، فیلد 'Badge' را پر کنید. می‌توانید عدد یا متن کوتاه وارد کنید.

= آیا با تم من سازگار است؟ =

بله، این پلاگین با تمام تم‌های استاندارد وردپرس سازگار است.

= چگونه رنگ‌ها را تغییر دهم؟ =

در پنل مدیریت پلاگین، تب 'رنگ‌ها' را انتخاب کنید و با استفاده از Color Picker رنگ‌های دلخواه را انتخاب کنید.

= آیا با صفحه‌سازها سازگار است؟ =

بله، با Elementor، WPBakery، Divi و سایر صفحه‌سازهای محبوب سازگار است.

= چگونه استایل را تغییر دهم؟ =

در پنل مدیریت، تب 'استایل‌ها' را انتخاب کنید و یکی از 10 استایل موجود را انتخاب کنید.

= آیا بر سرعت سایت تأثیر می‌گذارد؟ =

خیر، کدها بهینه‌سازی شده‌اند و فقط در موبایل بارگذاری می‌شوند.

= آیا RTL را پشتیبانی می‌کند؟ =

بله، کاملاً از زبان‌های راست‌به‌چپ مانند فارسی و عربی پشتیبانی می‌کند.
